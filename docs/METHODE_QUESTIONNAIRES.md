# Méthode obligatoire pour les modifications

Toute modification planifiée du produit suit ce cycle :

1. définir un seul thème de modification ;
2. préparer un questionnaire de 10 à 20 questions maximum ;
3. proposer des réponses courtes de type A, B, C ou D ;
4. intégrer les réponses libres lorsque la liste ne suffit pas ;
5. reformuler les décisions et repérer les contradictions ;
6. enregistrer la décision consolidée ;
7. modifier ensemble les composants concernés ;
8. vérifier le parcours complet et les règles absolues ;
9. fournir une nouvelle version cohérente.

Thèmes de questionnaires possibles : interface d’un écran, fonctionnalités, automatisation, moteur IA, documents, contrôles, navigation, rôles et agences.

Les questionnaires ne doivent pas mélanger plusieurs chantiers sans lien. Une correction urgente de sécurité ou un défaut empêchant l’application de démarrer peut être corrigé directement ; elle doit ensuite être signalée.
